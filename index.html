📚 Ficha de Consulta Rápida: Logaritmos

Un logaritmo responde a la pregunta: "¿A qué exponente debo elevar la base $a$ para obtener el número $b$?". Revisa las propiedades clave antes de empezar a practicar.

Definición Base P.1
$$\log_a(b) = c \iff a^c = b$$

La base $a$ debe ser positiva y distinta de 1 ($a > 0, a \neq 1$), y el argumento $b > 0$.

Ejemplo: $\log_2(8) = 3$ porque $2^3 = 8$.
Producto a Suma P.2
$$\log_a(x \cdot y) = \log_a(x) + \log_a(y)$$

El logaritmo de una multiplicación es igual a la suma de los logaritmos de cada factor.

Ejemplo: $\log(2 \cdot 5) = \log(2) + \log(5) = \log(10) = 1$.
Cociente a Resta P.3
$$\log_a\left(\frac{x}{y}\right) = \log_a(x) - \log_a(y)$$

El logaritmo de una división es igual a la resta del logaritmo del numerador menos el del denominador.

Ejemplo: $\log_3(81/9) = \log_3(81) - \log_3(9) = 4 - 2 = 2$.
Regla de la Potencia P.4
$$\log_a(x^k) = k \cdot \log_a(x)$$

El exponente del argumento pasa delante del logaritmo multiplicando ("Regla del Sombrero").

Ejemplo: $\log_2(8^5) = 5 \cdot \log_2(8) = 5 \cdot 3 = 15$.
Logaritmo de una Raíz P.5
$$\log_a(\sqrt[n]{x}) = \frac{1}{n} \cdot \log_a(x) = \frac{\log_a(x)}{n}$$

Como $\sqrt[n]{x} = x^{1/n}$, es una consecuencia directa de la regla de la potencia.

Ejemplo: $\log_5(\sqrt[3]{25}) = \frac{1}{3} \cdot \log_5(25) = \frac{2}{3}$.
Casos Base & Cambio Base P.6
$$\log_a(1) = 0 \quad \text{y} \quad \log_a(a) = 1$$
$$\log_a(b) = \frac{\log_c(b)}{\log_c(a)}$$

Si la base no se escribe, es decimal ($\log_{10} x = \log x$). Si la base es $e$, se escribe $\ln(x)$.

Ejemplo: $\log_2(2) = 1$, $\log_2(1) = 0$.
